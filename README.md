# BenReader downloads

BenReader is an Android ebook reader with its own ivory-and-copper book/B icon, familiar shelf and reading controls, and automatic checks for signed updates.

[Download the latest Android release](https://github.com/Benighter/BenReader-Releases/releases/latest)

This repository contains release APKs, update metadata, checksums and release notes only. Implementation source is maintained privately at Benighter/BenReader. Android asks for approval before installing updates.

BenReader's identity, icon, settings design and update integration are custom additions by Benighter. Reading components by Flyersoft and the original library authors retain their copyrights, credits and licences. Branding does not transfer ownership of those components or grant rights to books.
