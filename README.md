# BenReader downloads

BenReader is an Android ebook reader with an original book icon, familiar shelf and reading controls, and automatic checks for signed updates.

[Download the latest Android release](https://github.com/Benighter/BenReader-Releases/releases/latest)

This repository contains release APKs, update metadata, checksums and release notes only. Implementation source is maintained privately at Benighter/BenReader. Android asks for approval before installing updates.

BenReader's identity and update integration are custom additions by Benighter. Its recovered Moon+ Reader 10.5 reading engine, original author credits and third-party library licences remain applicable. Branding does not transfer ownership of those components or grant rights to books.
